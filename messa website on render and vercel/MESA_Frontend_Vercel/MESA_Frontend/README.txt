MESA FRONTEND PACKAGE
=====================
This folder contains the responsive MESA website interface and your supplied food photos/video.
It is designed to run together with the separate MESA_Backend package.
Do not open index.html directly; the backend serves it and connects account, booking, menu and order actions.
Extract MESA_Frontend and MESA_Backend side-by-side, then run MESA_Backend\START-MESA.bat.
The website opens at http://127.0.0.1:5000 on the PC. Use the LAN address printed by the backend on your phone (same Wi-Fi).
Video autoplay: browsers block autoplay with sound. The video starts automatically muted, and the sound control enables audio after a tap. This is a browser security rule, not a missing feature.
